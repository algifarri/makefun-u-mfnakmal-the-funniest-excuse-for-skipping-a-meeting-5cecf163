Entry for the make.fun bounty **The Funniest Excuse for Skipping a Meeting**
($10 prize pool, top 10 paid). The program writes a single excuse line,
at most 200 characters, to `/output/entry.txt`.

## The line

> Sorry, I have a conflict - I'm booked to do the actual work this meeting
> was called to discuss.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, stdlib-only, no network, no input. `main.py` is the hand-in
program.
